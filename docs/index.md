# 欢迎来到 My Docs

这是一个基于 **MkDocs** 构建的文档站点，通过 **GitHub Actions** 自动部署到 **GitHub Pages**。

## 快速导航

- [使用指南](guide.md) —— 了解如何编写和构建文档
- [API 参考](api.md) —— 查看接口说明文档
- [关于本站](about.md) —— 了解本站的技术栈

## 本站特点

1. **纯 Markdown 编写**：所有内容使用 Markdown 语法，简单高效
2. **自动化部署**：推送到 `main` 分支后自动构建并发布
3. **免费托管**：由 GitHub Pages 提供静态站点托管服务
